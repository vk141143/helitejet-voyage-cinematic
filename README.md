# HELITEJET Elysian Realm

Build a completely new HELITEJET website from zero. Ignore all prior designs and create an ultra-premium immersive cinematic digital world, not a conventional travel, corporate, SaaS, or booking site. Implement the user’s full specification: scroll-controlled camera-like storytelling, believable layered 3D/parallax depth, cinematic transitions across aviation, yachts, mobility, residences, experiences, destinations, membership, HELITEJET Private, concierge, about, and request access; minimal HJ/MENU UI and fullscreen cinematic menu; real routes exactly as requested; reusable scene architecture and centralized content. Use sophisticated obsidian/midnight/ivory/champagne palette, editorial serif type, subtle metallic gold, no glassmorphism/cards/grids/sidebar/standard hero/navbar. Prioritize a visually exceptional, polished desktop experience with responsive recomposed mobile and prefers-reduced-motion support. Enable Lovable Cloud if needed for the request-access journey and contact/concierge submissions. Use visual assets thoughtfully and optimize animation/media loading.
